# LTW Bài 7: SPA & React

Gồm 2 bài thực hành:

## Bài 1 - Virtual Calculator
Đáp ứng yêu cầu:
- Component `Display` hiển thị biểu thức và kết quả.
- Component `Button` nhận props `label`, `color`.
- Dùng `useState` lưu biểu thức hiện tại.
- Có các phép `+`, `-`, `×`, `÷`, `C`, `DEL`, `=`.

Chạy:
```bash
cd bai1-virtual-calculator
npm install
npm run dev
```

## Bài 2 - Trang CV bằng React
Đáp ứng yêu cầu:
- Có ít nhất 4 component: `Header`, `Section`, `SkillList`, `ProjectList`.
- Kỹ năng và dự án lưu trong mảng rồi truyền qua props.
- `Section` sử dụng `children`.
- Giao diện responsive.

Chạy:
```bash
cd bai2-cv-react
npm install
npm run dev
```

Bạn có thể sửa dữ liệu cá nhân trong `src/App.jsx`.
